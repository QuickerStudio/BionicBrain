# 仿生行为学

大模型只是抽象化的虚拟处理器。

面对复杂任务的时候，仍需要行为指令集，把繁杂的任务拆解成单位简单的行为动作。 
 
然而这种仿生行为解释器和行为树一般人是开发不出来的，我研究了一年多，发现这些功能只能在超算上模拟。  

未来是虚拟仿生学的世界。  

是为机器人仿生意识形态的准备做基础理论研究。

为什么人类只有少数简单的行为就可以虚拟出一个完整的精神世界？  
听说读写看，抓捏跑跳摇。  
这简单的十个行为几乎涵盖了所有的执行任务。  
人类是基于视觉引导行为的生物。  
信号路径：眼睛 - 视觉神经系统 - 主观意识神经系统 - 潜意识神经系统-本能辅助神经系统。

主观意识神经系统-抽象思维模式：  
- 快速思考  
- 深度思考  
- 检索思考  
- 直觉思考
- 反馈思考

知识是纯思维活动。

反馈思考是检索思考和深度思考的混合思考形态，用于论证事实。

直觉思考基于当前生存环境的经验积累，已经经过环境验证的训练完成的知识或经验，是快速思考的第二种形态，相当于快速思考的收藏夹。直觉思考专注于从环境中抽象出思维模式和思想方法和数据处理模式而不是数据本身。

创造性思考是直觉链路式深度思考的混合模式表现形态，是意识边缘化的多模式混合思考能力。

创造性思维基于直觉思考的数据库累积，达到一定的规模就会出现相对应的创造能力等级。创造性思维专注于直觉思考和数据结构的整合推理过程，反复迭代抽象方法。

直觉思考和创造性思考的数据集规模决定着意识形态上的差异的心机指数和思维先进性的聪明指数。

经验是基于知识产生的行为验证。

快速思考包含了大量的基本行为。

深度思考包含了大量的技能，由简单行为和复杂行为组成的混合任务系统。

快速思考用于调用自身的行为能力的本能反应。

深度思考用于解析环境和自身行为能力的行为模式的过程推理。

---

再来回顾一下，我们是如何产生意识的。
简单来说，我们是基于神经细胞的生命活动来产生意识的。神经细胞是随机链接附近的神经突触来产生电化学信号链路的，由于神经细胞活动几乎可以称为二维空间，所以我们的脑神经网络拥有很多层级，这在大规模的数据生成上动态调用了不同数量级的神经元。  

随着感官刺激的电信号密度激发不同神经网络内部的电化学应受区域，就形成了数据块。传输到记忆神经系统层级——记忆是对于人的历史事件频繁反复刺激构成的神经细胞记忆效应，会随着新陈代谢过程损失一部分神经细胞（不同类型的神经细胞的分裂复制的代谢速率和链接行为是不一样的，这解释了为什么会产生快速和慢速两种思维或记忆模式）——对于以往经验的匹配来形成不同的思维模式，大致有两种：纯思维活动，以及带有操作目标的行为思维互动。

那行为树是怎么产生的呢？

行为树产生于感官刺激和部分脑神经始终处于低功耗活跃状态。其产生过程具有随机性，但经过操作目标的训练和验证  
（视觉神经系统是主观意识神经系统的主导系统之一，其他还有听觉、味觉和嗅觉——味觉和嗅觉统称为味觉的不同形态，触觉是次要主观意识系统）  
后被区分为有用行为和无用行为。只要是人脑能够产生的行为，都是行为树上的一环，只是意识没有正确的匹配系统，缺少验证的环境。

神经细胞在受到电化学刺激后，会产生应激反应，改变原有的电化学内部结构，然后根据附近神经细胞传来的信号进行重组，分化成不同类型的神经细胞。

仿生神经细胞应该包含：
- 2 个记忆单元
- 1 个逻辑单元
- 1 个行为树匹配单元

分别对应着主控意识系统、推理转换行为系统以及行为树管理系统。

不难发现，我们的身体大部分的行动器官都具有两个相反的行为方向。

所以从我们最先进的行为系统手的关节运动中抽象出方向和矢量控制两个记忆单元。
从环境中的事件推理过程中抽象出1个逻辑单元来模仿神经元细胞的电化学刺激信号的传输处理过程。

再从神经元细胞的应激性记忆效应中抽象出1个行为树匹配单元来模仿神经细胞的分化功能，
* 或成为行为中的一环。
* 或分化为记忆神经细胞。

大脑神经细胞的这种特质使得处理复杂任务可以快速响应不同规模的神经链路网络。

目前，机器人的发展已经具备大脑功能，但仍缺乏仿生脑干和脊髓。  
其中，脑干和小脑充当着行为树操作管理系统的角色，而脊髓神经系统则是连接感官系统与物理世界的管理平台。
