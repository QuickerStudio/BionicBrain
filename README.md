# 大模型只是抽象化的虚拟处理器。
面对复杂任务的时候，仍需要行为指令集，把繁杂的任务拆解成单位简单的行为动作。
然而这种仿生行为解释器和行为树一般人是开发不出来的，我研究了一年多，发现这些功能只能在超算上模拟。
未来是虚拟仿生学的世界。
是为机器人仿生意识形态的准备做基础理论研究。
为什么人类只有少数简单的行为就可以虚拟出一个完整的精神世界？
听说读写看，抓捏跑跳摇。
这简单的十个行为几乎涵盖了所有的执行任务。
人类是基于视觉引导行为的生物。
信号路径：眼睛-视觉神经系统-主观意识神经系统-潜意识神经系统。
主观意识神经系统-抽象思维模式：快速思考，深度思考，检索思考，直觉思考（已经训练好的知识或者经验,是快速思考的第二种形态，相当于快速思考的收藏夹），反思（是检索思考和深度思考的混合思考形态，用于论证事实），快速思考包含了大量的基本行为，深度思考包含了大量的技能，由简单行为和复杂行为组成的混合任务系统。
再来回顾一下，我们是如何产生意识的，简单来说我们是基于神经细胞的生命活动来产生意识的。神经细胞是随即链接附近的神经突触来产生电化学信号链路的，由于神经细胞活动在几乎可以称为二维空间，所以我们的脑神经网路是有很多层级，这在大规模的数据生成上动态调用了不同数量级的神经元。
随着感官刺激的电信号密度来激发不同神经网路内部的电化学应受区域就形成了数据块。
传输到记忆神经系统层级，（记忆是对于人的历史事件频繁反复刺激构成的神经细胞的记忆效应，会随着新陈代谢过程损失一部分神经细胞，神经细胞的分裂复制的行为是不一样的）对于以往经验的匹配来形成不同的思维模式，大致有两种，纯思维活动，带有操作目标的行为的思维互动。
那行为树是怎么产生的呢？
行为树产生于感官刺激和部分脑神经始终处于低功耗活跃状态，产生的过程是随机性的，但是经过操作目标的训练和验证（视觉神经系统是主观意识神经系统的主导系统之一其他还有听觉味觉和嗅觉，味觉和嗅觉统称味觉的不同形态，触觉是次要主观意识系统），被区分为有用行为和无用行为，但是只要是人脑能够产生的行为都是行为树上的一环，只是意识没有正确的匹配系统，缺少验证的环境。
